OVERVIEW

ChezDeElise is an experimental local artificial intelligence
environment designed to operate independently of continuous
Internet access.

The system combines:

  > LOCAL LANGUAGE MODELS
  > HARDWARE INTERFACES
  > CAMERA / SENSOR INPUT
  > LOCAL AUTOMATION
  > OFFLINE REFERENCE MATERIAL
  > MOBILE COMPUTING
  > HUMAN-MACHINE INTERACTION

The objective is not to build a chatbot.

The objective is to build a useful machine.
