---------------------------------------------------------------

OVERVIEW

XOPR is a persistent monitoring and communications terminal
built around repurposed hardware.

Its job is simple:

  WATCH.
  LISTEN.
  DISPLAY.
  REPORT.

Preferably while looking like it knows something you don't.

---------------------------------------------------------------

SYSTEM ROLES

  > NETWORK STATUS
  > LOCAL SERVICE MONITORING
  > COMMUNICATIONS
  > ALERT DISPLAY
  > OSINT / FLASH REPORT DISPLAY
  > TERMINAL ACCESS
  > PASSIVE WATCH FUNCTIONS

---------------------------------------------------------------

DESIGN NOTES

XOPR is not intended to be invisible.

It is intended to look like a machine that has a job.

Controls should be understandable.

Displays should be readable.

Status should be obvious.

And if a red indicator light can be added without creating
a new point of failure, the red indicator light is going in.
