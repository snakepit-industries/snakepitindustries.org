PRESERVATION POLICY

  [01] PRESERVE ORIGINAL FILES.

  [02] PRESERVE ORIGINAL FILENAMES WHEN PRACTICAL.

  [03] PRESERVE FILE TIMESTAMPS WHEN RECOVERABLE.

  [04] HASH ORIGINAL DIGITAL ARTIFACTS.

  [05] IDENTIFY MODIFIED OR CONVERTED COPIES.

  [06] SCANS SHOULD REPRESENT THE ORIGINAL DOCUMENT.

  [07] TRANSCRIPTS SHOULD NOT REPLACE ORIGINAL SCANS.

ARCHIVAL NOTE

Old information is not automatically correct.

New information is not automatically better.

Preservation answers:

"WHAT DID THE RECORD SAY?"

It does not automatically answer:

"WAS THE RECORD RIGHT?"

Those are different questions.
