# Snakepit Industries

**Building Solutions That Bite.**

Snakepit Industries is an independent collection of computing,
electronics, RF, artificial intelligence, archival, and experimental
projects.

The website is intentionally hand-written in HTML and designed around
an amber monochrome terminal interface.

No framework is required.

No build system is required.

No content management system is required.

The website is a website.

## Current Projects

- ChezDeElise — Local AI / BuilderOS
- XOPR — Watchman Terminal
- Sonar — RF Situational Awareness
- WIG FLASHREP — OSINT Reporting
- Nightrider — Mobile Node

## Website

https://snakepitindustries.org

Best viewed with:

- Netscape Navigator 3.0
- 800x600 resolution
- 256 colors
- 28.8K modem or better

Only two colors are currently used.

254 colors are reserved for future expansion.
